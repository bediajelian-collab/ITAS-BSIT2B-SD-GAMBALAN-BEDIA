## Setup Instructions

*Requirements*
- Java version: 27.0.1.1
- IDE: NetBeans: NetBeans 21

*How to run*
1. Open the project folder in NetBeans.
2. Run ServerMain.java first (the server).
3. Run the client file (ChatClient.java).
4. Enter the server IP and port when asked.

*IP and Port*
- IP address: [192.168.1.4]
- Port: [5000]
